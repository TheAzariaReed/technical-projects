# Machine Learning — Visualization Driven Model Analysis

## Overview
This repository contains visualization-focused machine learning studies centered on feature behavior, dimensionality reduction, classification analysis, and predictive modeling interpretation. The projects emphasize **analytical visualization, comparative evaluation, and evidence-backed interpretation** across structured datasets.

## Objective
- Visualize feature relationships and class behavior across datasets
- Evaluate how data structure influences predictive and classification performance
- Compare model behavior using statistical and visual analysis techniques
- Support analytical conclusions through quantitative metrics and graphical interpretation

## Projects

### Iris_Visualization
Visualization and regression analysis using the Iris dataset with emphasis on:
- Correlation analysis
- Feature distribution visualization
- Predictive regression evaluation
- RMSE-based model assessment

#### Evidence
- **Technical Report:** `IrisDataset_FeatureRelationshipVisualization/Writing/Iris_Visualization_Report.pdf`
- **Code:** `IrisDataset_FeatureRelationshipVisualization/Code/`

### IrisIndianPines_Visualization
Visualization and classification analysis using the Iris and Indian Pines datasets with emphasis on:
- PCA and LDA projection analysis
- Class separation visualization
- Comparative classification performance
- Dimensionality reduction interpretation

#### Evidence
- **Technical Report:** `IrisIndianPinesDataset_DataSeparationVisualization/Writing/IrisIndianPines_Visualization_Report.pdf`
- **Code:** `IrisIndianPinesDataset_DataSeparationVisualization/Code/`

## Methodology
- Data preprocessing and normalization
- Statistical feature analysis
- Comparative visualization pipelines
- Regression and classification evaluation
- Quantitative performance measurement
- Projection-space and distribution analysis

## Key Findings
- Visualization techniques reveal meaningful differences in feature separability and model behavior
- Certain feature spaces support stronger predictive and classification performance
- Dimensionality reduction improves interpretability while preserving critical structural information
- Comparative plots provide measurable insight into generalization and class overlap

## Limitations
- Results remain constrained to the selected datasets and preprocessing assumptions
- Visualization quality and separability depend on feature structure and class distribution
- Conclusions reflect the scope and experimental configurations used in these studies
