# Machine Learning — Foundations

## Overview
This repository contains foundational machine learning implementations focused on regression, classification, optimization, and feature normalization. The projects emphasize **core algorithm behavior, mathematical interpretation, and foundational predictive modeling workflows** using supervised learning methods implemented from first principles.

## Objective
- Develop foundational understanding of supervised machine learning algorithms
- Explore optimization and convergence behavior in predictive models
- Analyze how feature scaling and normalization influence performance
- Implement and evaluate regression and classification techniques using structured datasets

## Projects

### LinearRegression_GradientDescent
Linear regression implementation focused on optimization behavior and parameter convergence with emphasis on:
- Gradient descent optimization
- Cost minimization behavior
- Iterative parameter updates
- Predictive regression foundations

#### Evidence
- **Code:** `LinearRegression_GradientDescent/Code/`

### LogisticRegression_Classification
Binary and multiclass classification implementation using logistic regression with emphasis on:
- Sigmoid-based classification behavior
- Decision boundary modeling
- Probability-driven prediction
- Foundational classification workflows

#### Evidence
- **Code:** `LogisticRegression_Classification/Code/`

### MultivariateRegression_FeatureNormalization
Multivariable regression analysis focused on normalization and feature scaling effects with emphasis on:
- Feature normalization techniques
- Multivariate regression behavior
- Predictive performance stability
- Numerical optimization foundations

#### Evidence
- **Code:** `MultivariateRegression_FeatureNormalization/Code/`

## Methodology
- Supervised learning implementation from foundational principles
- Gradient-based optimization techniques
- Statistical feature preprocessing
- Regression and classification evaluation
- Numerical parameter analysis
- Predictive performance assessment

## Key Findings
- Feature scaling and normalization significantly influence optimization stability and convergence behavior
- Gradient descent provides an effective foundation for iterative predictive model training
- Logistic regression effectively models probability-based classification boundaries
- Foundational machine learning algorithms reveal important relationships between data structure, optimization, and predictive behavior

## Limitations
- Results remain bounded to the selected datasets and implementation assumptions
- Foundational implementations prioritize interpretability and learning objectives over production optimization
- Model performance may vary under alternative preprocessing, tuning, and dataset configurations
