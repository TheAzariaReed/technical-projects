# UX Usability Study — Tuition Calculator Evaluation

## Overview
This project evaluates the usability, workflow effectiveness, and user interaction quality of a tuition calculator application through structured UX analysis and evidence-backed usability assessment. The emphasis is on **user-centered evaluation, interface effectiveness, workflow analysis, and actionable usability findings**.

## Objective
- Evaluate overall usability and interaction flow within the application
- Identify user friction points and workflow inefficiencies
- Assess interface clarity, accessibility, and navigation behavior
- Support usability conclusions through structured analytical findings

## Methodology
- User workflow and interaction analysis
- Interface and navigation evaluation
- Observation of usability barriers and inefficiencies
- Documentation of usability findings and improvement opportunities
- Comparative evaluation of expected versus observed user behavior

## Evidence
- **Technical Report:** `Writing/TuitionCalculator_UsabilityEvaluation_Report.pdf`

## Key Findings
- Workflow structure and interface organization significantly influence user efficiency and task completion behavior
- Certain interaction patterns introduce unnecessary cognitive and navigational overhead
- Structured usability evaluation reveals measurable opportunities for interface and workflow improvement
- Analytical UX findings support clearer and more intuitive user interaction design

## Limitations
- Results reflect the evaluated application state and selected usability scenarios
- User interaction behavior may vary across different user populations and experience levels
- Findings remain bounded to the workflows and evaluation methods used in this study
